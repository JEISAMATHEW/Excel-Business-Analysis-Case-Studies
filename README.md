# Excel Business Analysis – Practical Case Studies

## 📌 Project Overview

The **Excel Business Analysis – Practical Case Studies** project is a collection of four Excel-based business analysis exercises designed to build the core analytical skills used by Business Analysts: project planning, forecasting, scenario testing, and decision-making.

The project follows an end-to-end analyst workflow:

**Project Planning → Sales Forecasting → What-If Analysis
→ Scenario Comparison → Business Recommendation**

## 🏢 Industry

**Business Analytics / Cross-Industry (Project Management, Sales, Food Delivery)**

## 💡 Business Problem

Business Analysts are regularly asked to plan projects, predict future performance, test the impact of changing conditions, and recommend the best course of action to management. Excel is one of the most widely used tools to perform this analysis, but it requires combining several techniques — timelines, forecasting, and scenario modeling — into one coherent decision-making process.

## 🎯 Objective

Demonstrate core Business Analyst skills in Excel by:

* Planning and tracking a project using a Gantt Chart
* Forecasting future sales from historical data
* Testing the effect of changing business inputs using What-If Analysis
* Comparing multiple business scenarios to support a management decision

## ✨ Key Features

* Gantt Chart built from task start dates and durations
* Automatic duration calculation and overlap identification
* Monthly sales trend visualization
* Six-month sales forecast using Forecast Sheet and FORECAST.LINEAR()
* Profit calculation using Sales − Expenses
* Best Case / Normal Case / Worst Case scenario modeling
* Scenario Manager summary reports
* Profit and profit-margin comparison across scenarios
* Column charts comparing sales, expenses, and profit
* Management-style final recommendation

## 📊 Case Studies Included

**Case Study 1 – Gantt Chart**
Task list with Start Date, End Date, and Duration, converted into a Stacked Bar Chart to visualize the project timeline.

**Case Study 2 – Sales Forecasting**
Historical monthly sales data used to project the next six months and identify the overall trend.

**Case Study 3 – What-If Analysis & Scenario Manager**
Sales and Expenses used as changing cells to build Best/Normal/Worst Case scenarios and compare profit outcomes.

**Case Study 4 – Business Scenario Comparison**
A food-delivery business case comparing three quarterly scenarios across Sales, Variable Cost, Total Expenses, Profit, and Profit Margin %.

## 🧹 Analysis Workflow (per Case Study)

1. Organize raw task/sales/scenario data
2. Add calculated fields (Duration, Profit, Profit Margin %, etc.)
3. Build the relevant chart type (Stacked Bar, Line, or Column)
4. Run Excel's built-in tools (Forecast Sheet, Scenario Manager) where applicable
5. Interpret the results (trend, risk, highest profit, etc.)
6. Summarize findings in business language for management

## 🧮 Key Formulas Used

| Purpose | Formula |
|---|---|
| Task Duration | `= End Date − Start Date + 1` |
| Sales Forecast | `= FORECAST.LINEAR(...)` |
| Profit | `= Sales − Expenses` |
| Profit Margin % | `= Profit / Sales` (formatted as %) |
